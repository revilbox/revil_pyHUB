# revil_pyHUB

Terminal hub for Python on Termux. Strict, no-nonsense, beginner-friendly.

## Install

    pkg install python git
    git clone https://github.com/YOUR_NAME/revil_pyHUB
    cd revil_pyHUB
    pip install -r requirements.txt
    python main.py

## Keys

- menu: digits to select, Q to quit
- explorer: UP/DOWN navigate, ENTER open/run, E edit, B back, U update
- explorer extras: N new file, M new dir, F2 rename, DEL delete, CTRL+L goto path
